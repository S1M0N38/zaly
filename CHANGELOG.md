# Changelog

Changes to zaly and all public npm packages are tracked here. Earlier package-specific changes remain in the [archived package changelogs](https://github.com/folke/zaly/tree/3c7e33075c873df0986c747ee8ffa1e52e9d63d3/packages).

## [0.0.9](https://github.com/folke/zaly/releases/tag/zaly-v0.0.9) (2026-10-14)

### Initial unified alpha release

This is a curated overview of the existing alpha, not a complete history of changes before this release.

- A hackable terminal coding agent with streaming Markdown, syntax highlighting, themes, selection, and terminal image support.
- Multiple model providers, model switching, and configurable reasoning effort.
- Persistent workspace sessions, context inspection, compaction, and tool-result masking.
- Built-in coding tools, managed background tasks, and explicit per-tool permissions.
- Extensible commands, skills, resource packs, and TypeScript plugins.
- Seven reusable public npm packages, published together at a shared version.

This release used the historical `zaly-v0.0.9` tag. Subsequent releases use `v<version>` and this single changelog.
